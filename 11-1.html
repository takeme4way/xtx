Web 前端长度单位

1. 绝对单位 px（像素）

px 是最常用的绝对单位，1px 表示屏幕上的一个物理像素点（实际渲染受设备像素比影响）。

width: 100px
width: 200px
width: 300px

2. 相对单位 em（相对于父元素字体大小）

父元素 font-size: 20px，所以 1em = 20px。em 会随父元素字体大小变化。

width: 10em = 200px
width: 20em = 400px

3. 相对单位 rem（相对于根元素字体大小）

根元素 html 默认 font-size: 16px，所以 1rem = 16px。rem 不受父元素影响，适合响应式布局。

width: 10rem = 160px
width: 20rem = 320px

4. 百分比 %（相对于父元素）

百分比相对于父元素的对应尺寸（宽度、高度等），常用于流式布局。

width: 25%
width: 50%
width: 75%
width: 100%

5. 视口单位 vw / vh（相对于视口）

1vw = 视口宽度的 1%，1vh = 视口高度的 1%。调整浏览器窗口大小可看到效果。

width: 25vw
width: 50vw
height: 10vh

6. 视口单位 vmin / vmax

1vmin = 视口宽高较小者的 1%，1vmax = 视口宽高较大者的 1%。

width: 50vmin
width: 50vmax

7. 其他单位 ch（字符宽度）

1ch 等于当前字体中字符 "0" 的宽度，常用于限制文本宽度（如每行字符数）。

width: 20ch

总结对比

单位 类型 参考基准 常见用途
px 绝对单位 物理像素 边框、阴影、固定尺寸
em 相对单位 父元素 font-size 组件内间距、可缩放组件
rem 相对单位 根元素 font-size 响应式布局、字体大小
% 相对单位 父元素尺寸 流式布局、宽度自适应
vw / vh 视口单位 视口宽 / 高 全屏布局、大屏适配
vmin / vmax 视口单位 视口宽高较小 / 大者 横竖屏适配
ch 相对单位 字符 "0" 宽度 文本列宽控制
