JavaScript 六种基本数据类型

点击"运行并查看"将在控制台输出 typeof 结果，同时页面下方实时显示

1. String 字符串typeof → "string"
var xtx_name = "许桐欣"; → string
2. Number 数字typeof → "number"
var xtx_age = 20; → number
3. Boolean 布尔typeof → "boolean"
var xtx_isStudent = true; → boolean
4. Null 空typeof → "object"
var xtx_empty = null; → object（历史遗留 bug）
5. Undefined 未定义typeof → "undefined"
var xtx_unknown; → undefined
6. Object 对象typeof → "object"
var xtx_info = {name:"许桐欣", grade:"大二"}; → object
