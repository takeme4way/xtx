JavaScript 程序结构：循环与条件

用可运行示例演示 if/else、switch、for、while、do-while、break/continue

1. if…else 条件分支条件

根据分数判断等级：≥90 优秀，≥80 良好，≥60 及格，否则不及格。

var score = 78; if (score >= 90) { grade = "优秀"; } else if (score >= 80) { grade = "良好"; } else if (score >= 60) { grade = "及格"; } else { grade = "不及格"; }

2. switch 多分支条件

根据数字 1-7 输出对应的星期，其它显示"无效"。

var day = 3; switch (day) { case 1: w = "星期一"; break; case 2: w = "星期二"; break; case 3: w = "星期三"; break; /* ...省略... */ default: w = "无效"; }

3. for 循环 — 九九乘法表循环

双层 for 循环生成九九乘法表。

for (var i = 1; i <= 9; i++) { for (var j = 1; j <= i; j++) { line += j + "×" + i + "=" + (i*j) + " "; } line += "\n"; }

4. while 循环 — 1到100求和循环

用 while 累加 1+2+…+100。

var sum = 0, n = 1; while (n <= 100) { sum += n; n++; }

5. do…while 循环循环

先执行一次循环体再判断条件：倒数 5…1。

var k = 5, s = ""; do { s += k + " "; k--; } while (k > 0);

6. break / continue — 跳出与跳过循环控制

输出 1-10 中所有奇数，遇到 7 时停止（break）；偶数用 continue 跳过。

var r = ""; for (var i = 1; i <= 10; i++) { if (i % 2 === 0) continue; // 跳过偶数 if (i === 7) break; // 遇7终止 r += i + " "; }
